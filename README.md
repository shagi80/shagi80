# Сергей Шагинян | 1С-разработчик

1С-разработчик с бэкграундом Python и Delphi. Пришел в разработку с позиции топ-менеджера производственного предприятия - отлично понимаю производственные процессы и работу инженерных систем. Я не просто пишу код по ТЗ - я решаю проблему бизнеса. Умею выстраивать архитектуру программных решений. Владею ООП, руководствуюсь SOLID, использую паттерны проектирования. Пишу чистый, производительный и масштабируемый код. 

## Ключевые навыки:
- **полный цикл:** от проектирования структуры метаданных, интерфейса управляемых форм, до вывода решения в эксплуатацию;
- **предметная область:** отчетность на производственных участках, складской учет, контроль прослеживаемости продукции, сложные сдельные расчеты, управление поставками;
- **интеграции:** REST API, WEB-сервисы, ТСД, Клеверенс, работа с промышленным оборудованием;
- **процессы:** удаленная работа в распределенной команде, GitFlow, код-ревью и CI/CD.
