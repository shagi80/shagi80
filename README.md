### Наиболее интересные проекты:

### Интеграция производственного цеха с 1С 7.7 в условиях полной изоляции
**Проблема:** удалённый сервер 1С 7.7, порты HTTP/Email закрыты для безопасности.<br>**Решение:** разработал мобильное приложение на платформе 1С для учёта сырьевых смесей; организовал обмен данными через VPN-туннель, используя API «Клеверенс: Склад 15» как прокси-шлюз; написал модули обработки на стороне 1С 7.7 для регламентного парсинга данных.<br>**Результат:** полностью исключён ручной перенос данных, сведены к нулю учётные ошибки.<br>**Публикация:** https://habr.com/ru/articles/1073106/

### Внешняя подсистема «Дисциплина» на базе 1С:ЗУП 3.1
**Проблема:** организация учёта дисциплинарной практики, ручное заполнение табелей.<br>
**Решение:** разработал внешнюю подсистему (СКД, регистры, управляемые формы) с оперативной записью документов в контур учёта.<br>
**Результат:** автоматизирован расчёт управленческих начислений, исключено ручное заполнение табелей, минимизирован риск фальсификации данных со стороны линейного персонала.<br>
**Публикация** и разбор: https://habr.com/ru/articles/1084330/

### Конфигурация 1С для анализа статистики гарантийного сервиса
**Проблема:** интеграция корпоративной сервисной платформы с 1С 8.<br>
**Решение:** разработал конфигурацию 1С:Предприятие 8 - собрал команду разработки из студентов Netology и в роли project-manager довёл проект до MVP1; самостоятельно реализовал связь конфигурации с web-сайтом через REST API и связь с 1С 7.7 через файловый обмен.<br>
**Результат:** процесс анализа результатов работы сервиса ускорился с нескольких дней до нескольких минут.<br>

### Обработка для загрузки данных с сайта ФТС
**Проблема:** выборка данных из статистических форм учёта.<br>
**Решение:** разработал внешнюю обработку, выполняющую загрузку, парсинг и обработку данных из реестров (xlsx) и статистических форм (xml).<br>
**Результат:** скорость подготовки отчёта выросла с 1,5–2 часов до 20 минут; полностью исключены арифметические ошибки и ошибки человеческой невнимательности.<br>

### Web-сервис для взаимодействия с сетью партнерских сервисных центров (Python/Django + 1C)
**Проблема:** получение, проверка и анализ отчетности 150+ гарантийных мастерских, своевременная и полная обработка заявок на запчасти.<br>
**Решение:** разработал web-сервис для сбора и автоматизированнной проверки отчетности, оформления заявок на запчасти и контроля за их движением. С системой внутреннего обмена сообщениями, REST API сервисом для интеграции с 1С8 и фаловой выгрузкой финансового итога в 1С7.<br>
**Результат:** сковозная автоматизация worflow сервиной службы позволила менее чем за год сократить штат подразделения с 5-ти до 2-х человек.<br>
